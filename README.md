# ChatFlow Frontend

ChatFlow 是一个现代化的聊天应用前端项目，使用 React + TypeScript + Vite 构建。

## 技术栈

- **框架**: React 18
- **语言**: TypeScript
- **构建工具**: Vite
- **UI 组件库**: 
  - Chakra UI
  - Chat UI Kit
  - React Flow
- **状态管理**: Redux Toolkit
- **路由**: React Router v6
- **表单处理**: React Hook Form + Yup
- **样式解决方案**: 
  - Tailwind CSS
  - Styled Components
  - Emotion
- **开发工具**:
  - ESLint
  - Prettier
  - TypeScript
  - PostCSS

## 环境要求

- Node.js >= 16
- npm >= 8

## 快速开始

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm start
```

3. 构建生产版本：
```bash
npm run build
```

4. 预览生产构建：
```bash
npm run serve
```
